# 研究室配属システム

学生の希望順位と研究室ごとの点数（GPA点 + 教員裁量点）から、安定マッチングで
研究室配属を決めるブラウザアプリです。

マッチングには [`hospital-resident-matching`](https://github.com/dfukagaw28/hospital-resident-matching)
の `stableMatch()`（学生側最適の受入保留アルゴリズム）を使います。

設計は [DESIGN.md](DESIGN.md) を参照してください。

## 動かす

```bash
npm install
npm run dev      # http://localhost:5173
```

`index.html` は `/src/main.ts` を TypeScript のまま読み込むので、Vite 経由でしか
動きません。静的に配信するときはバンドルしてください。

```bash
npm run build    # 型検査 + dist/ にバンドル
npm run preview  # dist/ を配信して確認
```

`dist/` は相対パス（`base: "./"`）で参照するので、GitHub Pages でもサブディレクトリ
でもそのまま置けます。

```bash
npm run typecheck
npm test
```

## 入力ファイル

4 種類のファイルをドラッグ＆ドロップします。種類はファイル名から推測し、外れて
いれば画面のプルダウンで直せます。`samples/` に匿名の合成データがあります。

| 種類 | 形式 | 枚数 |
| --- | --- | --- |
| 希望順位 | `学籍番号,氏名,第1希望,第2希望,…` | 1 |
| GPA | `学籍番号,GPA` | 1 |
| 研究室・定員 | `研究室,研究室名,定員` | 1 |
| 教員裁量点 | `研究室,学籍番号,裁量点` | 研究室ごと、またはまとめて 1 |

- 見出しは別名を許します（`学籍番号` / `学生番号` / `ID`、`裁量点` / `点数` / `得点` など）
- 希望の列は `第N希望` の N の順に読みます。そう名づけられた列が無ければ、学籍番号と
  氏名を除いた残りの列を左から順に希望とみなします
- 文字コードは UTF-8 と Shift_JIS を自動で見分けます（Excel の CSV は多くが後者）
- 書き出す CSV は Excel が文字化けしないよう BOM 付き UTF-8 です

これは **LMS のテキストと Excel を直接読めるようになるまでの暫定形式**です
（[DESIGN.md](DESIGN.md) の M3）。

## パラメータ

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 抽選シード | 読み込みごとにランダム | 総合点が同点のときの抽選に使う。結果に記録されるので再現できる |
| GPA 配点 | 40 | 全研究室で共通の持ち点 |
| GPA の満点 | 4.0 | `GPA / 満点 × 配点` で換算する |
| 裁量点 配点 | 60 | 研究室ごとの持ち点 |
| 裁量点の満点 | 60 | |
| 裁量点が無い学生 | 0 点として扱う | 「受け入れ不可」にすればその研究室には配属されない |

研究室どうしで裁量点の水準を揃える必要はありません。マッチングが使うのは研究室の
中での順序だけなので、ある研究室が全員に高い点を付けても結果は変わりません。

## 出力

結果は画面に出て、3 種類の CSV としてダウンロードできます。

- **学生別** — 学籍番号 / 氏名 / GPA / 抽選番号 / 配属研究室 / 第何希望 / 総合点 / 研究室内順位
- **研究室別** — 研究室ごとに、配属された学生を順位つきで
- **サマリ** — 使ったシードとパラメータ、希望順位の内訳、ブロッキングペア数

安定マッチングにはブロッキングペア（今の配属より互いを選びたい学生と研究室の組）が
存在しないので、結果画面でそれを検査しています。0 でなければデータか実装を疑って
ください。

## 個人情報について

計算はすべてブラウザ内で完結し、入力したファイルがサーバに送られることはありません。

実データ（学籍番号・氏名・GPA・裁量点）は `data/` に置いてください。`.gitignore` で
`data/`・`private/`・`*.xlsx`・`*.xls`・`*.csv` を除外しています。リポジトリに入れて
よいのは `samples/` 配下の匿名化した合成データだけです。
